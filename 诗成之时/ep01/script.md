# 第一集《早发白帝城》剧本

## 核心感受

江面越走越开，李白的神情也随之舒展。观众先看见他经历的晨行，再听他把这一程读成诗。

## 约 50 秒结构

1. 0-10 秒：晨光照亮江岸高处的白帝城，一叶木舟停在岸边。江水与风声先进入画面。
2. 10-20 秒：李白走上木舟，扶稳船边。旁白仅说：“清晨，李白从白帝城登舟，顺江向江陵而去。”
3. 20-30 秒：木舟离岸，山壁从两侧展开，远处传来猿声。李白站在舟前，望向江流去处，露出轻快神情。
4. 30-40 秒：李白放声诵读：“朝辞白帝彩云间，千里江陵一日还。”说完留出自然换气。
5. 40-50 秒：保持同一人物、衣着和木舟方向，李白接着诵读：“两岸猿声啼不住，轻舟已过万重山。”末句落下时，木舟行过近处山壁，远景仍可见江路。

## 声音原则

旁白和诵读不同时出现。整集以江水、风声和远处猿声连接镜头；诵读期间降低环境声，句末让江声重新清楚。诗人的声音应畅快、舒展，不增加原诗之外的字句。
