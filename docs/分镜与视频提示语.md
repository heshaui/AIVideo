# 分镜与视频提示语规范

## 用途

本规范用于把 `ep01/script.md` 等剧本改写为可制作的 `ep01/storyboard.md`，再逐镜整理成豆包网页可提交的视频提示语。每镜目标时长约 10 秒；时长、参考素材数量和控制方式以页面实际可用能力为准。

详细不等于堆砌形容词。优先写能在画面中检查的事实：谁从哪里出发、先做什么、与谁或什么接触、造成什么变化、最后停在哪里。一个片段内若同时要求过多动作、视角变化和对白，先拆镜。

## 每镜记录格式

每集 `storyboard.md` 开头记录画幅、统一画风、角色固定外观、场景方位和声音基调，并引用 `../project.md` 与共用素材。随后每镜按下列字段记录：

```md
## ep01_sh01｜镜头名称

- 剧本来源：场次及对应事件；本镜给观众的新信息。
- 预计时长：约 10 秒。
- 参考素材：实际文件的相对路径；逐张注明负责角色外观、场景、起始画面、末帧或动作参考。尚未下载的素材写“待制作”，不能当作现有文件。
- 起始画面：景别、机位、人物在画面中的左右与前后、朝向、距离、双手与随身物品、光线、上一镜留下的动作状态。
- 动作节拍：按先后写触发、移动路线、接触、反应和收势；秒数仅用于估算节奏。
- 摄影：一个主要机位与运镜，注明跟随对象、方向和停下的位置。
- 声音：逐字对白与说话人、发声先后、必要音效、背景音乐或环境声在首尾的状态。
- 结束画面：人物位置与姿态、持物状态、视线、镜头位置；说明下一镜从哪个可见状态接上。
- 可提交提示语：把上述可见内容写成一段顺序明确的完整描述；素材标签按网页实际上传顺序填写。
- 生成记录：下载文件、备选版本、选用版本、画面与声音的检查结果。
```

动作节拍可以在分镜里用 `开始 → 触发 → 接触 → 反应 → 收势` 展开。碰到多人交错、交接物品、转身或落地时，明确是哪只手、哪只脚，以及改变前后的状态。不要让人物或物品在两个片段之间无缘由地换位置。时段数字只是创作预算；视频提示语主要用“先、随后、最后”说明顺序，实际节奏要看生成结果。

## 视频提示语写法

1. 先确定本镜用到的真实参考图、上一段实际视频或末帧，并逐项说明用途。共用角色和场景外观以素材为准，文字重复必要的服装、道具和光线特征。
2. 用一句话固定起始构图和空间关系，例如“甲在画面左侧面向右，乙在画面右侧面向左，相距两步，廊柱在右后方”。
3. 依发生顺序写动作。动作场面至少说清发起者、路线、左右手脚、接触位置、对方的可见反应与最终收势。动作必须在约 10 秒内能被看清；过长的连续动作拆到下一段。
4. 指定景别、机位和一个主要运镜。镜头变化要服务于动作可读性；复杂动作优先保持人物全身及空间关系可见。
5. 最后写稳定的结束画面，供下一段复用。对白按剧本逐字填写，说明谁说、何时说；音乐、环境声和动作声音在接缝处如何延续也要写明。
6. 检查文字、参考素材与分镜是否冲突。不要只写“激烈交手”“电影感”一类无法核对的概括，也不要在单段内塞入整场动作戏。

## 动作场面示例

下面是单段示例，不预设豆包网页一定支持特定的素材标签。实际提交前按网页中上传的角色图、场景图及可用引用方式改写素材称呼。

**分镜设定**：雨后石板庭院，傍晚侧光。青衣甲在画面左侧，面向右；灰衣乙在画面右侧，面向左；两人相距约两步。固定中远景，能看清两人全身和脚下石板。本镜只完成一次进攻、化解与收势。

| 内部节奏 | 可见动作与结果 |
| --- | --- |
| 开始 | 乙左脚向画面左侧迈出一步，右拳直线伸向甲的胸前；甲保持视线盯住乙的肩和拳。 |
| 随后 | 甲左脚向画面左后方撤半步，身体侧转，左前臂将乙的右前臂引向画面右侧；两人的手臂确实接触。 |
| 接着 | 甲右手握住乙的右手腕，顺着乙前冲的方向向下带；乙上身前倾，右膝落到画面右侧石板，左手撑地稳住。 |
| 结尾 | 甲松开手腕，在画面左侧站稳，乙保持单膝落地并抬头看甲。两人停住片刻，供下一镜从相同站位接起。 |

**对应的视频提示语示例**：

> 参考已上传的青衣角色、灰衣角色和雨后庭院图片，保持两人的面容、衣着与庭院布局一致。傍晚侧光照在湿润石板上。固定中远景，两人全身始终在画面内：青衣甲站在左侧面向右，灰衣乙站在右侧面向左，相距两步。乙左脚向左迈出，右拳直线伸向甲胸前；甲左脚向左后方撤半步并侧身，用左前臂接触乙的右前臂，将它引向右侧。甲随即用右手握住乙的右手腕，顺着乙的前冲方向向下带；乙上身前倾，右膝落地，左手撑住石板。甲松手，在左侧站稳；乙留在右侧单膝落地，抬头看甲，结束前保持这一姿态。听到脚步落在湿石板、衣料摩擦和手臂接触的声音；本段没有对白，背景音乐保持上一段的节奏，结尾不断开。

这段示例的重点是画面方向与每次接触后的状态变化。若生成结果把人物左右位置颠倒、跳过接触、增加不需要的动作，或结尾姿态无法连接下一镜，应改写该镜或重新生成，不靠最终剪辑掩盖关键动作缺失。

## 参考资料

- [Seedance 2.0 官方介绍](https://seed.bytedance.com/en/seedance2_0)：确认文字、图片、音频、视频参考及联合生成的方向；豆包网页的实际功能仍需现场核对。
- [Google Cloud 视频提示语指南](https://cloud.google.com/vertex-ai/generative-ai/docs/video/video-gen-prompt-guide)：参考主体、动作、场景、机位和运镜的拆解方式。
- [Drama Skills](https://github.com/zenstory-ai/drama-skills)：参考分镜的起止状态、素材对应与动作链写法；其完整制作流程不直接套用本项目。
